# Покерный тренер

Ассистент для 6-max No-Limit Hold'em (кэш, 100bb): по раздаче даёт совет (fold / call / raise + сайзинг) и объясняет его.
Все числа считает код, а не LLM.

## Запуск

```bash
pip install -r requirements.txt
python -m poker_coach.ui
```

Консольный вариант:

```bash
python -m poker_coach.cli --hero "Ah Qh" --board "Kh 7h 2c" --pos BB --vpos BTN --line villain_open_hero_call --pot 8.5 --call 3 --stack 94.5
```

Тесты: `python -m pytest`

## Вкладки приложения

- **Игра против ботов** — стол на 2–9 игроков, позиции меняются каждую раздачу. Характеры ботов: стандартный, тайтовый, «телефон», агрессор; можно посадить случайных со скрытыми характерами. Тренер оценивает каждое решение, копит профиль каждого бота и подстраивает советы. Боты по желанию подстраиваются под игрока. Кнопка «Оверлей» открывает компактное окно тренера поверх остальных окон.
- **Разбор ситуации** — выставить любую раздачу один на один вручную и получить совет.
- **Разбор сессии** — загрузить hand history PokerStars и увидеть, где решения разошлись с тренером. Пример: `samples/pokerstars_sample.txt`.
- **Обучение** — учебник из 13 глав: правила, позиции, префлоп, математика, диапазоны, ставки, типы оппонентов, как работает солвер.

## Солвер на Rust

Флоп, тёрн и ривер один на один считает собственный солвер (CFR+) из каталога `solver_rs`. Сборка:

```bash
pip install maturin
```

```bash
cd solver_rs && maturin build --release && pip install target/wheels/solver_rs-*.whl
```

Без него приложение работает: ривер считает медленный солвер на Python, флоп и тёрн — эвристика.

| Улица | Дерево | Время решения |
|---|---|---|
| Ривер | ставки 33% и 75% банка, один рейз | около 0.07 с (на Python — 0.18 с) |
| Тёрн | ставки 33% и 75%, один рейз; на ривере ставка 75% без рейза; все 48 карт ривера | около 1.2 с |
| Флоп | ставка 50%, один рейз; тёрн 66%, ривер 75% без рейзов; по 10 случайных карт тёрна и ривера | около 2.5 с |

Диапазоны на тёрне и ривере берутся из решения прошлых улиц: солвер решает флоп, идёт по сыгранной линии и передаёт веса рук дальше. С этим решение на ривере занимает около 1.7 с (до 3 с).

## Оценка на PokerBench

```bash
python -m poker_coach.bench
```

Тестовые наборы PokerBench (arXiv:2501.08328): префлоп 1000 спотов, постфлоп — случайная выборка из 10 000 (seed 0).
AA — совпал тип действия, EM — совпал и размер (наш размер приводится к ближайшему доступному в споте).

Выборка 2000 спотов:

| Вариант | Постфлоп AA | Флоп | Тёрн | Ривер |
|---|---|---|---|---|
| A. Эвристика, диапазон только по префлопу | 63.9% | 64.1% | 59.4% | 67.3% |
| B. A + сужение диапазонов по истории ставок | 70.0% | 64.1% | 63.6% | 75.8% |
| C. B + пороги, подобранные на обучающей части (`--no-solver`) | 73.0% | 62.7% | 67.5% | 78.8% |
| D. C + солвер на тёрне и ривере (`--no-flop`, простое дерево тёрна) | 73.2% | 62.7% | 69.5% | 77.6% |
| E. D + солвер флопа, два размера ставки на тёрне | 73.8% | 75.4% | 68.8% | 77.6% |

Выборка 600 спотов (вариант с цепочкой решений считается долго):

| Вариант | Постфлоп AA | Флоп | Тёрн | Ривер |
|---|---|---|---|---|
| E. Диапазоны по правилам | 71.5% | 68.8% | 68.6% | 74.0% |
| F. E + диапазоны из решения прошлых улиц (`--solved-ranges`, по умолчанию в приложении) | 75.3% | 68.8% | 70.6% | 79.6% |

| Префлоп | AA | EM |
|---|---|---|
| Ручные чарты и упрощённые правила (`--no-table`) | 76.3% | 76.1% |
| Таблица из решений солвера (по умолчанию) | 99.0% | 98.2% |

Оговорки:

- Пороги эвристик (`poker_coach/data/params.json`) подобраны на 2400 спотах обучающей части PokerBench (`python -m poker_coach.tune`); на отложенных 2400 обучающих спотах точность выросла с 69.8% до 73.8%.
- Решения о солвере флопа, дереве тёрна и диапазонах из решения принимались по тестовой выборке, так что цифры E и F слегка оптимистичны. Флоп в выборке мал (142 и 32 спота), его цифры шумные.
- Солвер флопа перебирает не все продолжения борда, а по 10 случайных карт тёрна и ривера: это приближение, от набора карт ответ немного зависит.
- Две настройки дерева солвера («чек в агрессора» и сила диапазона колла) были подобраны на тестовой выборке раньше.
- Диапазоны из префлоп-таблицы солвера (`table_ranges`) выключены: с ними точность ниже.
- Префлоп-таблица собрана из обучающей части PokerBench. 795 из 1000 тестовых спотов встречаются в ней с той же линией и рукой; на 144 спотах, где руки в таблице нет и решение берётся по соседним рукам, точность 98.6%.
- С внешними солверами (PioSolver, GTO Wizard, postflop-solver) наш солвер не сверялся.

## Что внутри

| Модуль | Назначение |
|---|---|
| `state.py` | `GameState` и проверка ввода |
| `calc.py` | эквити против диапазона, ауты, шансы банка, SPR |
| `charts.py` | ручные префлоп-чарты (на них играют боты) |
| `preflop_gto.py` | префлоп-таблица из решений солвера: мультивей, лимпы, олл-ины |
| `ranges.py` | диапазоны по префлоп-линии, сужение по истории ставок |
| `coach.py` | совет (чарты на префлопе, правила на постфлопе) и текст разбора |
| `scenarios.py` | случайные учебные ситуации |
| `solver/` | интерфейс солвера (`base.py`), обёртка над солвером на Rust (`rust_cfr.py`), солвер ривера на Python (`river_cfr.py`) |
| `solver_rs/` | солвер флопа, тёрна и ривера на Rust |
| `params.py`, `tune.py` | пороги эвристик и их подбор на обучающей части PokerBench |
| `theory.py` | учебник для вкладки «Обучение» |
| `hh.py` | парсер hand history PokerStars и сверка решений с тренером |
| `bench.py` | прогон на PokerBench |
| `bots.py` | характеры ботов |
| `profile.py` | статистика оппонента и поправки к советам |
| `engine.py` | стол на 2–9 игроков, боты, сверка решений героя с тренером |
| `ui.py` | окно с тремя вкладками и оверлеем |

## Ограничения текущей версии

- Банки на трёх и более игроков считает эвристика, не солвер.
- Деревья солвера упрощены: мало размеров ставок, один рейз, на флопе — выборка продолжений борда.
- За столами на 7–9 игроков ранние позиции играются по диапазонам UTG стола 6-max: таблицы для них нет.
- Стартовые диапазоны — из ручных чартов; из-за цепочки решений ход бота на тёрне и ривере может занимать 1–3 секунды.
- У всех игроков в начале каждой раздачи 100 bb.
- Во вкладке «Разбор ситуации» история ставок не вводится, поэтому диапазоны там сужаются правилами.
- Разбор сессии понимает только формат PokerStars; скриншоты не поддерживаются.
- LLM не подключена: разбор собирается из шаблонов.
