# Покерный тренер

Ассистент для 6-max No-Limit Hold'em (кэш, 100bb): по раздаче даёт совет (fold / call / raise + сайзинг) и объясняет его.
Все числа считает код, а не LLM.

## Запуск

```bash
pip install -r requirements.txt
python -m poker_coach.ui
```

Консольный вариант:

```bash
python -m poker_coach.cli --hero "Ah Qh" --board "Kh 7h 2c" --pos BB --vpos BTN --line villain_open_hero_call --pot 8.5 --call 3 --stack 94.5
```

Тесты: `python -m pytest`

## Вкладки приложения

- **Игра против бота** — полная раздача один на один, тренер оценивает каждое решение. Четыре характера соперника (стандартный, тайтовый, «телефон», агрессор) или случайный со скрытым типом. Тренер копит статистику соперника и подстраивает советы под его профиль. Кнопка «Оверлей» открывает компактное окно тренера поверх остальных окон (данные берёт только со своего стола).
- **Разбор ситуации** — выставить любую раздачу вручную и получить совет.
- **Разбор сессии** — загрузить hand history PokerStars и увидеть, где решения разошлись с тренером. Пример: `samples/pokerstars_sample.txt`.

## Оценка на PokerBench

```bash
python -m poker_coach.bench
```

Тестовые наборы PokerBench (arXiv:2501.08328): префлоп 1000 спотов, постфлоп — случайная выборка 2000 из 10 000 (seed 0).
AA — совпал тип действия, EM — совпал и размер (наш размер приводится к ближайшему доступному в споте).

| Вариант | Постфлоп AA | Постфлоп EM | Флоп | Тёрн | Ривер |
|---|---|---|---|---|---|
| A. Эвристика, диапазон только по префлопу | 63.9% | 63.2% | 64.1% | 59.4% | 67.3% |
| B. A + сужение диапазонов по истории ставок | 70.0% | 69.4% | 64.1% | 63.6% | 75.8% |
| C. B + свой солвер на ривере (по умолчанию) | 69.7% | 69.1% | 64.1% | 63.6% | 75.2% |

| Префлоп | AA | EM |
|---|---|---|
| Ручные чарты и упрощённые правила (`--no-table`) | 76.3% | 76.1% |
| Таблица из решений солвера (по умолчанию) | 99.0% | 98.2% |

Оговорки:

- Префлоп-таблица собрана из обучающей части PokerBench (60 тысяч решений). 795 из 1000 тестовых спотов встречаются в ней с той же линией и рукой, поэтому 99% — это в основном проверка, что таблица прочитана верно. На 144 спотах, где такой руки в таблице нет и решение берётся по соседним рукам, точность 98.6%.
- Настройки солвера ривера («чек в агрессора», сила диапазона колла) подбирались на тестовой выборке постфлопа, так что его цифра немного оптимистична. Строка A посчитана до этой настройки.
- Солвер включён по умолчанию: по точности он теперь на уровне эвристики, но даёт частоты, EV и блефы. Отключается флагом `--no-solver` или `coach.SOLVER = None`.

## Что внутри

| Модуль | Назначение |
|---|---|
| `state.py` | `GameState` и проверка ввода |
| `calc.py` | эквити против диапазона, ауты, шансы банка, SPR |
| `charts.py` | ручные префлоп-чарты (на них играют боты) |
| `preflop_gto.py` | префлоп-таблица из решений солвера: мультивей, лимпы, олл-ины |
| `ranges.py` | диапазоны по префлоп-линии, сужение по истории ставок |
| `coach.py` | совет (чарты на префлопе, правила на постфлопе) и текст разбора |
| `scenarios.py` | случайные учебные ситуации |
| `solver/` | интерфейс солвера (`base.py`) и свой CFR+ для ривера (`river_cfr.py`) |
| `hh.py` | парсер hand history PokerStars и сверка решений с тренером |
| `bench.py` | прогон на PokerBench |
| `bots.py` | характеры ботов |
| `profile.py` | статистика оппонента и поправки к советам |
| `engine.py` | раздача один на один против бота, сверка решений с тренером |
| `ui.py` | окно с тремя вкладками и оверлеем |

## Ограничения текущей версии

- Ривер считает свой солвер (CFR+); флоп и тёрн — эвристика «эквити против шансов банка».
- Советы на префлопе берутся из таблицы решений солвера; диапазоны оппонента для постфлопа — всё ещё из ручных чартов.
- Только один оппонент. Во вкладке «Разбор ситуации» история ставок не вводится: диапазон сужается только по текущей ставке.
- Разбор сессии понимает только формат PokerStars; скриншоты пока не поддерживаются.
- Бот играет по тем же чартам и правилам, что и тренер, и почти не блефует.
- LLM пока не подключена: разбор собирается из шаблонов.
